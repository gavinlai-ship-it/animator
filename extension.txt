Describe your extension(s) here before implementing them.
My extnesion is going to add color and curves to the animator. I added two new shape variants, colorline and circle without changing point, line or path. The colors are integers in 0xRRGGBB form becasue the interpreter has no string values. Both of the shapes are registered in the constructor list in evaluator.gleam and defined in shape.gleam so that user programs can construct them the same way they constructed the Point and Line. In render.gleam, a ColorLine becomes a two point polyline drawn in its own color and a Circle is a 49 point polyline that is made by rotating a point by 7.5 degrees continuously and so the vanvas Javascript does not need any changes. Additionally, I plan to add a example drawing to the library so that users can see the new shapes right when they make it.
